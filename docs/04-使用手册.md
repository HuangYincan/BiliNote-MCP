# 04-使用手册

> 本手册面向两种读者：**人类用户**（如何安装、配置、调试）与 **agent**（如何调用这套 MCP 工具完成"生成视频笔记"）。agent 工作流见下方 [Agent 工作流](#agent-工作流)。

## 前提

- Python ≥ 3.11（推荐 3.12，`.python-version` 已锁定）
- **FFmpeg**：`brew install ffmpeg`（Linux：`apt install ffmpeg`）
- 二选一：
  - LLM 供应商 API Key（DeepSeek / OpenAI / Qwen 等，通过 `add_provider` 配置）
  - 或复用已有 BiliNote 数据库（设置 `DATABASE_URL` 指向旧库）

## 安装与注册

```bash
# 1. 安装依赖（创建 venv）
uv sync
# 或 pip install -e .

# 2. 注册 MCP（二选一）
#    项目级：把仓库根 .mcp.json 放到你的 Claude Code 项目根（或直接在此仓库内用）
#    用户级：claude mcp add bilinote -- bilinote-mcp

# 3. 安装 Skill（让 agent 知道怎么用）
#    ln -sf "$(pwd)/.claude/skills/bilinote" ~/.claude/skills/bilinote
```

## 启动与自检

```bash
uv run bilinote-mcp            # 前台运行 MCP（stdio）
# 或在 Claude Code 里 /mcp 查看是否注册成功
```

调用 `health_check`，确认：
- `ffmpeg: ok`（缺失则先安装 FFmpeg）
- `db: ok`
- `whisper_model: ready`（本地转写需要；未就绪可 `download_transcriber_model` 或改用 groq）

## 工具参考

| 工具 | 参数要点 | 返回要点 |
|------|----------|----------|
| `generate_note` | `video_url`（必填）、`platform`（可省略自动识别）、`quality`(fast/medium/slow)、`model_name`、`provider_id`、`format`(["toc","link","screenshot","summary"])、`style`、`screenshot`、`link` | `{task_id}` |
| `get_task_status` | `task_id` | `{status, message, result?}`，SUCCESS 时 `result.markdown` |
| `wait_for_note` | `task_id`、`timeout`(秒，默认120) | 阻塞轮询到 SUCCESS/FAILED，返回 Markdown |
| `list_providers` | — | 供应商列表（id/name/type/enabled） |
| `add_provider` | `name`、`api_key`、`base_url`、`type` | 新供应商 id |
| `list_models` | `provider_id` | 该供应商可用模型（实时 /v1/models，回退本地 DB） |
| `add_model` | `provider_id`、`model_name` | 手动把模型名加入供应商（接口不可用时） |
| `get_transcriber_config` | — | 当前转写引擎与模型尺寸 |
| `set_transcriber` | `transcriber_type`(fast-whisper/groq/bcut/…)、`whisper_model_size` | 新配置 |
| `list_transcriber_models` | — | 本地已下载的 whisper 模型 |
| `download_transcriber_model` | `model_size`、`transcriber_type` | 触发下载（后台） |
| `health_check` | — | ffmpeg / db / whisper 状态 |
| `validate_url` | `url` | 识别到的平台 |
| `set_downloader_cookie` | `platform`、`cookie` | — |

> `style` 可选值：`minimal` / `detailed` / `academic` / `tutorial` / `xiaohongshu` / `life_journal` / `task_oriented` / `business` / `meeting_minutes`。
> `format` 含 `screenshot` 时需模型支持视频理解且会显著变慢；`link` 会在笔记中插入时间点链接。

## Skill 使用

本仓库自带 Claude Code Skill（`.claude/skills/bilinote/SKILL.md`），它会教 agent 用上面的工具完成「视频 → 笔记」的标准流程。安装：

```bash
ln -sf "$(pwd)/.claude/skills/bilinote" ~/.claude/skills/bilinote
```

之后在 Claude Code 里说「帮我给这个视频做笔记」+ 链接即可触发。

## Agent 工作流

一次典型的"给视频做笔记"任务，agent 应按顺序调用：

1. `health_check` —— 确认 ffmpeg/db 就绪；
2. `list_providers` —— 确认有可用的 LLM 供应商与模型（没有则 `add_provider`，再 `list_models` 确认模型已添加）；
3. `generate_note(video_url=..., provider_id=..., model_name=...)` —— 拿 task_id；
4. `get_task_status(task_id)` 循环轮询（或直接 `wait_for_note(task_id)`）；
5. SUCCESS 后拿到 `result.markdown` —— **阅读该 Markdown 并用它回答用户的所有问题**（不要发明笔记里没有的内容）；
6. 若用户要的是"视频里某个细节"，可在 Markdown 之外再 `get_task_status` 拿 `result.transcript`（完整转写）辅助定位。

示例对话：

> 用户：帮我给这个视频做个笔记 https://www.youtube.com/watch?v=xxxx
>
> agent：`validate_url` → youtube；`list_providers` 确认模型；`generate_note` → 轮询 → SUCCESS；展示 Markdown 并总结要点。

## 配置说明

### LLM 供应商

```text
add_provider(name="DeepSeek", api_key="sk-...", base_url="https://api.deepseek.com", type="deepseek")
list_models(provider_id)    # 拉取模型列表
```

### 转写引擎

- 本地离线：`set_transcriber("fast-whisper", "small")`（首次会下载模型，几 MB~1GB）；
- 云端快速：`set_transcriber("groq")`（需在代码/环境配置 groq key）。

### 平台 Cookie（B 站等）

部分平台需登录 Cookie 才能下载高清/完整内容：
`set_downloader_cookie(platform="bilibili", cookie="SESSDATA=...")`。

## 故障排查

| 现象 | 原因 / 解决 |
|------|-------------|
| `health_check` 显示 `ffmpeg: missing` | 安装 FFmpeg（`brew install ffmpeg`）后重启 |
| 提示"不支持的转写器" | 用 `get_transcriber_config` 查看，`set_transcriber` 改回 `fast-whisper` |
| whisper 转写时报模型未下载 | `download_transcriber_model(model_size="small")` 后重试，或切 `groq` |
| `generate_note` 报"供应商不存在" | 先 `add_provider` 并 `list_models`，把正确 `provider_id`/`model_name` 传入 |
| `validate_url` 返回不支持 | 该链接平台不在支持列表（youtube/bilibili/tiktok/kuaishou/douyin/local） |
| 任务长时间卡住 | `get_task_status` 看 message；可能视频很长或模型下载中，耐心等待或换小模型 |
| 中文乱码/内容差 | 检查所选模型能力；`style` 会影响输出格式 |
